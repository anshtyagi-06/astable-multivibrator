# Astable Multivibrator

A B.Tech Electronics and Communication Engineering project demonstrating the working of an Astable Multivibrator circuit.

## Overview
An Astable Multivibrator is an electronic circuit that continuously switches between two states without requiring an external trigger signal. It generates a continuous oscillating output.

## Project Objective
To build and understand the working of an Astable Multivibrator using electronic components and observe its oscillatory behaviour.

## Components
- Transistors
- Resistors
- Capacitors
- LEDs
- Breadboard
- Connecting wires
- DC power supply

## Working Principle
The Astable Multivibrator consists of two switching stages coupled through capacitors. The capacitors alternately charge and discharge, causing the transistors to switch ON and OFF. This continuous switching produces oscillations.

## Applications
- LED blinking circuits
- Clock pulse generation
- Oscillator circuits
- Timing applications
- Digital electronics
